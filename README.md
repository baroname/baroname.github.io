# Baro Name Bayeta – Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a web browser.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with your email address.
2. Replace `YOUR_GITHUB_USERNAME` with your GitHub username.
3. Add your real education details.
4. Keep only skills you can confidently demonstrate.
5. Add links to completed project repositories and demos.
6. Update project descriptions to reflect their actual status.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish your site. Its address will be `https://YOUR_GITHUB_USERNAME.github.io/`.
